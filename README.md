# Abigail 360

Proyecto sencillo de Angular con A-Frame: imagen panorámica 360°, cámara y texto 3D «Abigail».

## Cómo ejecutar
1. Instala Node.js (versión 20 o 22 LTS compatible con Angular 19).
2. Abre esta carpeta en Visual Studio Code.
3. Abre Terminal > Nueva terminal.
4. Ejecuta `npm install`.
5. Ejecuta `npm start`.
6. Abre `http://localhost:4200/` si no se abre automáticamente.

El archivo `public/360.jpg` es la imagen panorámica. Puedes reemplazarlo por otra foto equirectangular 360° manteniendo el mismo nombre.

La librería A-Frame se carga desde su CDN y necesita conexión a Internet.
